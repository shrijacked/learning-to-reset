Extension Controller View

A side-by-side picture of the three implemented directions beyond one-shot reset: full clean, selective retention, and recall-aware memory.

Why This Matters

The baseline paper setup is one-shot reset, but the more ambitious contribution path is already in code: preserving only selected information or routing useful facts through an explicit memory channel.

What Is New Here

These are not just planned ideas. The multi-clean, selective-retention, and memory-aware modules already exist in the repository and can be compared through a shared evaluation utility.

What Is Still Missing

The extension controllers still need stronger baseline arithmetic performance before larger comparisons will be meaningful, so the next work is mostly better supervision and scaled runs.
