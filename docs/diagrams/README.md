# Diagrams

This folder contains shareable HTML diagrams for the current project state.

- `system-overview.html`
  - high-level view of the repository architecture, data flow, runtime flow, and extension track
- `baseline-loop.html`
  - end-to-end baseline workflow from sources to training, evaluation, comparison, and recovery-data feedback
- `extensions-view.html`
  - side-by-side view of the implemented extension controllers beyond one-shot reset

Open any file directly in a browser.
